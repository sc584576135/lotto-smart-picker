# 大乐透智能选号 — 移动端 APP（HarmonyOS 2.0 / Android）

## 目标设备
华为 Mate 40，HarmonyOS 2.0.0.280（Android 10 兼容层，API 29）。

## 架构
纯前端 Web 应用（单文件 HTML/CSS/JS），无后端、无登录。
通过 WebView 壳打包成 APK，离线可用，数据存本地 localStorage。

## 功能保留清单
- 选号：普通/复式/胆拖
- 规则：和值、跨度、奇偶、区间比、PAIR_MAP 对码、断区、杀号
- 分层：热/温/冷/极冷
- 覆盖率优化：注间重叠最小化
- 注数档位：1-50（含 34 注 = 约 90%）
- 历史数据录入/查看
- 号码导出（复制/分享）
- 无登录

## 文件
- `index.html` — 单文件应用
- `app.js` / `app.css` — 可分离时使用
